# Flow Pipes · 连线成流

Free single-file HTML5 puzzle game. Connect matching colored dots with
glowing pipes — cover the whole board for a perfect star. 30 procedural
levels (5×5 to 9×9, 2–8 color pairs), one hint per level, progress saved.

**Play:** https://shuangyueliao.github.io/flow-pipes/

- Drag with mouse or touch, procedural WebAudio scale notes
- Every level generator-verified to have a full-board solution
- Procedural visuals, zero dependencies, no external assets
